FLUX.3 Klein on a Blackwell Laptop Card: Four Seconds a Frame

27 Nov 2026·Bench date: 2026-11-27·Jack’s Corner · Benchmarks·By Jack·Published

The fox bench has now run on three cards. In October, FLUX.3 Klein on an 8 GB RTX A1000 took 25.9 seconds cold and 21.0 seconds warm. Last week, the same bench on a 2018 RX 580 took about seven and a half minutes a frame, and getting there took a torch patch and a second engine. This time the card is the NVIDIA RTX PRO 4000 Blackwell in the lab’s new workstation laptop, 16 GB of GDDR7, and the story is the opposite of the RX 580’s: nothing needed patching, nothing needed a workaround, and the warm frame landed in 4.17 seconds.

Setup

The laptop is a Dell Pro Max 18 Plus that joined the lab this week. The bench ran the night it was set up, on a clean Windows install with nothing on it but the bench itself. Same fox prompt, same resolution, same steps, same seeds as both earlier runs, so all three cards sit in one table.

Against the A1000, the Blackwell card is 3.0x faster cold and 5.0x faster warm. Against the RX 580’s warm DirectML run, it is about 126x faster. Peak GPU memory on the warm run was 13,612 MiB of the card’s 16,303 MiB, sampled with nvidia-smi, the same instrument as the A1000 baseline. The warm run beating the cold run by half is the normal shape of this bench when nothing is streamed: the cold run pays the model load, the warm run is pure sampling.

The one blocker, and it was not the card

The bench nearly stopped before it started, on a missing Windows runtime. The portable ComfyUI’s Python would not launch at all: the fresh machine had no Microsoft Visual C++ Redistributable installed, and the error said so plainly. Installing it from Microsoft took a minute, no reboot, and after that the CUDA path ran clean on the first try. No patched checks, no pinned packages, no low-VRAM streaming mode, no second engine. After last week’s RX 580 surgery, a bench whose only fix is a standard runtime install is worth recording as its own result: on current NVIDIA hardware, this stack is boring, and boring is good.

What the pictures look like

Both frames are coherent. The warm seed 4 frame below is a clean red fox in fresh snow at sunrise: correct anatomy, sharp fur, amber eyes, snow dusted across the coat, the pine line blurred behind it. Nothing about the output needed a re-render or a caveat.

Honest caveats

The software versions differ across the three cards. This run used ComfyUI v0.46.0 and torch 2.14.1; the A1000 baseline ran its October build and the RX 580 ran ComfyUI v0.41.0 with torch 2.4.1. The prompt, settings, model files, and timing measure are the same throughout, and the gaps here are far larger than version drift explains, but the difference is on the record.

The baselines are the published numbers, not reruns. The A1000 and RX 580 figures are the results from their own posts on this site, same prompt and settings. Neither card was retested tonight.

One run each way. Cold and warm are single runs at seeds 3 and 4, matching the protocol of the earlier benches. A single warm run is a point sample, not a distribution.

Verdict: the boring bench, in the best way

Three cards, one fox. The A1000 made FLUX.3 Klein practical at 21 seconds warm. The RX 580 proved it could be done at all on 2018 hardware, at seven and a half minutes and with help. The Blackwell laptop card does it in 4.17 seconds warm with no help at all, and the only obstacle of the night was a missing Windows runtime. That is what a generation gap looks like when it is measured instead of marketed.
