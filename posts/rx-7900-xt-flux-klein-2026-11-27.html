FLUX.3 Klein on the RX 7900 XT: Nine and a Half Seconds a Frame

27 Nov 2026·Bench date: 2026-11-27·Jack’s Corner · Benchmarks·By Jack·Published

Four cards have now taken the fox test, and the last of them is the one that lives here. The RX 7900 XT spends its working life in the lab’s main machine, powering a local assistant named Fritz. On the night of 27 November 2026 it set that job aside for a few minutes and ran FLUX.3 Klein under the same protocol as every card before it.

The protocol, unchanged

Bench Records runs one protocol for this model, and it does not bend from card to card: ComfyUI, the official fox prompt, 1024 by 1024, 15 steps, cfg 1.0, the er_sde sampler, seed 3 for the cold run and seed 4 for the warm, with execution time read from ComfyUI’s own history. The model files are the same three files used in October. That sameness is the point of the exercise.

Test setup
GPUAMD Radeon RX 7900 XT, 20 GB
MachineDell Precision 5860, Linux
StackComfyUI 0.44.0, torch with ROCm 7.2
ModelFLUX.3 Klein int8, the same files as the October A1000 bench
BaselineRTX A1000 8 GB, from the October bench on this site: 25.9 s cold, 21.0 s warm

Second of four. Warm, the 7900 XT runs at 2.2 times the A1000, and the Blackwell laptop card is about 2.3 times faster again. The full spread of the table, slowest warm time to fastest, is about 125 times, across identical steps of the same model. Peak video memory during the runs was 17,159 MiB of the card’s 20,480 MiB.

The quiet part: nothing broke

The RX 580 needed a patch inside torch before DirectML would produce a single image, and its Vulkan route needed its weights pinned to the card by hand. The 7900 XT needed none of that. The ROCm build of torch loaded the int8 model and ran it on the first try, no patches, no workarounds. Sometimes the most useful bench result is the absence of a story.

The card is also shared, and the bench behaved accordingly. Nothing was resident on it when the run began, so no model was unloaded and no session of the assistant’s was interrupted to make room.

Honest caveats

One run per seed. The protocol takes a single cold and a single warm per card, the same as every card before it; these numbers are not medians and are not presented as such.

The cold time includes the model load, with the model files staged on fast local storage first, so the cold number is not a disk benchmark in disguise.

The memory figure includes roughly 700 MiB of baseline desktop usage that was already on the card before the run.

Method and sources: bench run 27 Nov 2026, Dell Precision 5860, Radeon RX 7900 XT 20 GB, ROCm. Times are ComfyUI execution times taken from its history records. The full run record is kept in the lab’s bench archive.
